## Improvements

### Faster RocksDB Space Reclamation

Bottom-most RocksDB compactions for partition stores and log servers now use the normal low-priority compaction pool instead of a dedicated single-thread pool. This allows disk space to be reclaimed faster while keeping compactions within the existing background-compaction budget.

No configuration or migration changes are required.

_Related: [#5217](https://github.com/restatedev/restate/pull/5217)_

### Restate UI 1.0.19

The bundled Restate UI is updated to **v1.0.19**. It adds a query inspector for diagnosing the SQL issued by UI pages and an explicit unreachable health state. It also refines page layouts and fixes race conditions in query and filter controls.

No configuration or migration changes are required.

_Related: [Restate UI v1.0.19](https://github.com/restatedev/restate-web-ui/releases/tag/v1.0.19), [#5218](https://github.com/restatedev/restate/pull/5218)_
