# Admin API

The OpenAPI document at `/openapi` is generated by utoipa from `src/rest_api` and
`crates/admin-rest-model`. Users generate clients from it with standard tools.

After changing handlers, responses, or models, run:

```sh
cargo xtask generate-rest-api-doc > /tmp/admin-openapi.json
npx -y @openapitools/openapi-generator-cli validate -i /tmp/admin-openapi.json
```

It MUST report zero errors. See `crates/admin-rest-model/AGENTS.md` for fixing errors.
